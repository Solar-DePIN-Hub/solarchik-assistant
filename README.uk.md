# Solarchik Assistant — Colosseum (Crypto World's Fair)

English: [README.md](README.md).

**Solarchik Assistant** — нативний Android кишеньковий AI на Solana: голосовий друг **Sol**, AI-секретар дзвінків, агентські NFT з гаманцем і невеликий щоденний check-in. Дах-ран лише як бонус звички, не як головний продукт.

Хакатон: **Colosseum Crypto World's Fair**, дедлайн **12 жовтня 2026, 23:59 PT** (**13 жовтня 2026, 09:59 Київ**), категорія **AI Platforms / Agents**, трек Solana.

Окремий репозиторій для Colosseum. Ігрова подача CLOCK IN лишається в [Solar-DePIN-Hub/Solarchik](https://github.com/Solar-DePIN-Hub/Solarchik).

## Що спробувати суддям

1. Поговорити з Sol через мікрофон (мова як у телефоні).
2. Відкрити інбокс секретаря: короткі підсумки, нагадування, блок.
3. Змінтити або запустити strategy NFT на **Solana devnet** (лише paper/devnet).
4. Зробити щоденний check-in (memo в мережі).

## Чесно про стан

Зараз у `main` лежить збірка **0.22.3** з `native-full` (rooftop). Home переробляємо під Sol + великий мікрофон. `applicationId` поки той самий, що в грі (`net.solardepin.solarchik`) — окремий id для Assistant узгоджуємо перед фінальним сабмітом.
